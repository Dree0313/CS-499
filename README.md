🌀 1. ChadaTech Retrospective
Course: Software Development Lifecycle Report

ChadaTech was a team-based project built around the Scrum Agile framework. The primary goal was not just to develop software but to experience the collaborative structure of Agile, including the roles of Product Owner, Scrum Master, Developer, and Tester.

As the Tester, my role focused on ensuring that all user stories met client expectations through defined functional requirements. For example, I verified that the webpage layout displayed the top five destinations correctly and supported smooth scrolling.

🧠 Key Learnings

Role Collaboration: Worked closely with the Scrum Master, Product Owner, and Developer to ensure project alignment and quality.

Communication Clarity: Practiced professional correspondence to clarify user stories and requirements.

Flexibility Under Change: Reprioritized user stories mid-project to adjust to new client requirements without sacrificing project momentum.

Scrum Tools: Used Gantt charts and user stories to maintain transparency, track progress, and coordinate deliverables.

🧩 Takeaway

The Agile approach proved far more adaptable than traditional Waterfall methods, enabling rapid adjustments and stronger collaboration. This project solidified my understanding of real-world software lifecycles and the importance of structured communication in team environments.

💡 3. Raspberry Pi LED Display
Course: Hardware Systems & Prototyping

This project involved assembling and programming a Raspberry Pi connected to LEDs on a solderless breadboard and an LED display.

Description

The goal was to gain hands-on experience with GPIO pin control and hardware debugging. Initially, the wiring on the breadboard was incorrect, but through testing and reconfiguration, I successfully powered and programmed the LED components to respond to code-based triggers.

Skills Gained

Circuit design and assembly

Python scripting for GPIO control

Troubleshooting and debugging hardware connections

Software Development Lifecycle (SDLC)

Agile / Scrum Methodology

Python Programming & OOP Principles

Hardware Integration (Raspberry Pi)

Collaborative Problem-Solving
